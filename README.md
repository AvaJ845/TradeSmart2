# TradeSmart2
#Python application using Streamlit that focuses on stablecoin arbitrage opportunities across US-based exchanges. 
#This platform will help users identify relative value discrepancies between stablecoins and analyze whether these gaps will converge or diverge, aiming to generate daily profits.
## Features

1. **Market Scanner**: Identifies relative value discrepancies in stablecoin prices across exchanges.
2. **Pair Analysis**: Analyzes historical price relationships to predict convergence.
3. **Technical Analysis**: Provides indicators and signals to time entry/exit points.
4. **Risk Analysis**: Evaluates risk-reward profiles and optimizes position sizing.
5. **Educational Resources**: Offers comprehensive guides on stablecoin arbitrage.
